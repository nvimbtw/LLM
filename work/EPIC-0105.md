## Description

Two workstreams that share one goal: the chinchilla-small run has consumed
essentially all the data on disk, and the next model up needs both a larger
pretrain corpus and an SFT stage that can be run more than one way.

**Goal.** After this epic:

1. A pretrain run can draw on ~50 GB of text across six sources instead of
   1.5 GB across four, with every fetcher taking a `--mb` budget so any single
   source can be dialled down without editing it.
2. An SFT run selects *named sets* the same way a pretrain run selects datasets
   — so a no-thinking fine-tune and a thinking fine-tune are two independent
   runs producing two separate models to compare, **not** two stages of one
   curriculum.

**The invariant that makes (2) work.** The built SFT dataset is currently three
fixed singleton files (`datasets/sft_corpus.bin`, `sft_mask.bin`,
`sft_segments.json`). The moment a run can choose *what* to build, one build
silently overwrites the other and `rebuild_dataset: false` reuses whichever
corpus happened to be written last. Every later child depends on that being
fixed first — see ISSUE-0107, which is a live bug today via `strip_thinking`.

**Why the SFT refactor comes before the SFT data.** TODO-0106 defines the
per-set folder layout (`data/sft/<set>/*.jsonl`); the fetcher in TODO-0119
writes into it. Fetching first would mean fetching twice.

**What is deliberately out of scope.** No LLM-generated SFT data —
`scripts/generate_sft_llm.py` stays as it is and is not scaled up. Thinking
traces come from a real dataset (HuggingFaceTB/smoltalk2), converted by a
prepare script that injects this repo's markers.

## Definition of done

Every child `done`, plus an end-to-end check:

- `GET /sft/datasets` lists at least `smoltalk2-nothink` and `smoltalk2-think`.
- Two SFT runs from the same base model, one selecting each set, both complete
  and leave **two** distinct built datasets on disk — neither having overwritten
  the other, and a second run of either with `rebuild_dataset: false` reusing
  its own corpus rather than the sibling's.
- `GET /datasets` lists the six pretrain corpora, and a pretrain run selecting
  all of them packs without a fetcher rerun.
