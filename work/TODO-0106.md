## Description

SFT conversations live flat at `data/sft/*.jsonl` and
`sft.conversation_files()` globs all of them with no way to ask for a subset.
Pretrain data solved this problem already: `data/input/<Dataset>/*.txt`, one
folder per selectable dataset, read by `corpus/sources.py`. SFT should work the
same way so a run can pick a thinking set or a non-thinking set.

**Wanted.** A per-set folder layout and the collection functions over it:

    data/sft/<set>/*.jsonl        one folder per selectable SFT set

plus, mirroring `sources.datasets()` / `catalogue()` / `collect()`:

- `sft_datasets()` — every set folder, sorted
- `sft_catalogue()` — `{name, files, bytes}` per set, for a caller composing a run
- `collect_sft(names=None)` — the `.jsonl` paths for the named sets, all of them
  when `names` is empty, sorted for determinism, honouring a `{name, count}` cap
  the same way `sources.collect` does

**Backwards compatibility.** Loose `.jsonl` sitting directly in `data/sft/`
must keep working, collected as a set named `root` — exactly the fallback
`sources.collect` already implements for loose `.txt` in `input/`. This is what
stops the 777 MB currently on disk from disappearing the moment this lands;
TODO-0110 moves it properly afterwards.

**Shape of the fix.** `sources.py` already has `_selection()` duck-typing and
the cap logic, and neither is text-specific. Factor rather than copy — a second
near-identical `collect` would be the duplication R6 exists to prevent. Whether
that means extending `sources.py` with a glob-pattern-and-base-dir parameter or
adding a small `sft_sources.py` that reuses its helpers is the Builder's call;
what must not happen is two hand-maintained copies of the same selection rules.

`storage.py` needs the per-set path (`sft_set_dir(name)`) and `scripts/paths.py`
its writer-side counterpart, so the fetchers in TODO-0119 have somewhere to
write. Update the layout docstrings in both files — `storage.py`'s module
docstring and `paths.py`'s both currently document `sft/*.jsonl` as flat.

## Definition of done

- `data/sft/<set>/*.jsonl` is collected per set; loose root `.jsonl` still
  collected as `root`.
- Selection accepts a bare name, a `{name, count}` mapping, and a
  `DatasetSelection`, identically to pretrain.
- No duplicated copy of the cap/selection logic.
- `storage.py` and `scripts/paths.py` docstrings describe the real layout.

### Builder · 2026-08-10
Generalized `sources.py` into `names_in`/`paths_in`/`catalogue_in`/`collect_in` over any base dir + glob; the pretrain functions are thin wrappers and SFT binds the same rules to `sft/`. Added `storage.sft_set_dir` and `paths.sft_set_dir`, and layout docstrings in both.

Fixed a bug found while doing this: `collect()` appended loose root files *unconditionally*, so an explicit selection also dragged in whatever sat at the root. That would have broken the whole point of the epic — selecting `smoltalk2-think` would have silently mixed in other data. `root` is now a real, named, selectable dataset instead of an implicit extra.
