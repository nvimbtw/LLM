## Description

The HTTP layer: `src/routes/` (3,773 lines over sixteen files, largest
`jobs.rs` at 1,139 and `chat.rs` at 787), `extractors.rs` (107, the actix auth
extractor used by nine route files) and `ws.rs` (29, socket auth). 3,909 lines
total — the largest single move in EPIC-0094, and the last one, because it sits
at the top of the dependency order and depends on nearly everything below it.

`extractors.rs` and `ws.rs` join `routes` rather than standing alone: both are
pure actix glue (`extractors` pulls the authenticated user off a request via
`crypto` + `db::user`, `ws` authenticates a socket) with no meaning outside the
HTTP layer. A crate each would be two crates that only ever have one consumer.

Move to `crates/web` with `routes`, `extractors` and `ws` as modules.
Dependencies: `jobs`, `db`, `crypto`, `storage`, `training`, `synth`,
`labeling`, plus `actix-web`, `actix-ws`, `actix-multipart`, `futures-util`.

Preserve the layering rules `backend/CLAUDE.md` states for this layer — they are
the reason it is a coherent crate at all:

- Route files are HTTP-only: parse, call `db::`, map to `HttpResponse`. No SQL
  moves here during the extraction.
- Each file keeps its `pub fn configure(cfg: &mut web::ServiceConfig)`, composed
  in `routes/mod.rs` via `web::scope(...)`.
- Never serialize a db struct straight back to a client.

`routes/mod.rs`'s `configure` composition is what `main.rs` calls, so it must
stay `pub` at the crate root (`web::routes::configure`, or re-exported as
`web::configure` — pick one and use it consistently in TODO-0104).

## Definition of done

- `crates/web/` exists with `routes`, `extractors` and `ws` as modules; all are
  gone from `backend/src/` and their `mod` declarations are removed from
  `main.rs`.
- `grep -rn "crate::routes\|crate::extractors\|crate::ws" backend/src
  backend/crates` returns nothing.
- `cargo build` and `cargo clippy --all-targets` clean; `cargo test` passes.
- The app starts and serves: log in, list models, open a chat socket and get a
  streamed reply. A route layer that compiles can still be unregistered.
