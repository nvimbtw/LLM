## Description

`training.rs` (2,928 lines — the largest file in the backend) builds the
datasets a run trains on and owns the entry points into the `llm` crate:
`TrainConfig`/`TrainMode`, `build_dataset`, `build_sft_dataset`,
`build_kto_dataset`, the chat split (`chat_destination`), `synthetic`, and the
curriculum plumbing.

Its only in-binary dependency is `storage` (already a crate after TODO-0096).
Everything else it touches is external: `llm` (62 references) and `tokenize`
(28). No `sqlx`, no `actix`. It is cleanly extractable.

Move to `crates/training`, depending on `llm`, `tokenize`, `storage`,
`serde`/`serde_json`. Rewrite `crate::training::` → `training::` at its call
sites: `queue.rs`, `train_worker.rs`, `cycle.rs`, `routes/training.rs`,
`routes/jobs.rs`.

**Do not split the file.** It badly wants to be
`{config, dataset, sft, kto, curriculum}.rs`, and that is worth doing — but as
its own artifact after this epic lands, so this diff stays a move that a
reviewer can confirm by inspection. Note the follow-up in a Builder comment
rather than acting on it.

Watch the naming when it becomes a crate: `training::TrainConfig` stutters
(R21). Do not rename here — that is a separate artifact, and renaming inside a
move makes the move unreviewable. Flag it for the Auditor.

## Definition of done

- `crates/training/` exists; `backend/src/training.rs` is gone and
  `mod training;` is removed from `main.rs`.
- `grep -rn "crate::training" backend/src backend/crates` returns nothing
  (note: `crate::training::` *inside* the `llm` crate refers to `llm`'s own
  `training` module and must not be touched).
- The crate's `Cargo.toml` names no `sqlx` and no `actix-web`.
- `cargo build` and `cargo clippy --all-targets` clean; `cargo test` passes.
