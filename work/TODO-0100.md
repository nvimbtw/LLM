## Description

`synth.rs` (2,274 lines) generates synthetic SFT/chat data, including the path
that calls an external model over HTTP (`reqwest`, keyed by `SFT_API_KEY`) and
writes the results into `raw/sft/`. Its only in-binary dependency is `storage`;
otherwise it uses `llm`, `tokenize`, `reqwest`, `tokio` and `serde_json`.

Move to `crates/synth`. Consumers to rewrite from `crate::synth::`:
`queue.rs`, `routes/synth.rs`, `routes/jobs.rs`.

Two things to preserve exactly:

- `reqwest` is configured `default-features = false` with an explicit feature
  list (`json`, `rustls`, `charset`, `http2`, `system-proxy`). Copy that
  declaration verbatim into the new manifest; picking up default features drags
  in a second TLS stack.
- `synth.rs` contains an `exclusive_data_dir()` guard held across `.await`
  points (clippy flags it today at `synth.rs:2109`). That is a pre-existing
  warning in the binary crate. Moving the file does not fix or worsen it —
  leave the behaviour alone, and if the lint newly *fails* the build in a
  fresh crate, silence it with a justified `#[allow]` and file the real fix
  separately rather than changing locking semantics inside a move.

As with TODO-0099, do not split the file; note the follow-up instead.
