## Description

`/home/x_x/Programming/LLM/pg19/train` holds 28,602 `.txt` files, 11 GB — the
PG19 Project Gutenberg corpus, already downloaded, currently read by nothing.
There are `test/` and `validation/` splits beside it. It is the cheapest 11 GB
in this epic: no network, no parquet, no quality classifier.

It is also the only *long-form narrative* source in the mix. Everything else
being fetched is web text, encyclopedia entries, Q&A or code — documents of a
few thousand characters with no long-range structure. A book is the one thing in
the corpus that rewards a context window.

**Wanted.** `scripts/prepare_pg19.py`, on the TODO-0111 helper, reading the
local directory and writing sharded `.txt` into `data/input/Books` with the
usual `--mb` budget, `<|endoftext|>` separators and manifest.

**Things specific to this source:**

- **It is local.** Take a `--src` pointing at the PG19 directory, defaulting to
  the path above, and fail with a clear message if it is absent rather than
  trying to download anything.
- **Books are huge.** A single volume can be several hundred KB — larger than
  one output shard. Do not split a book across shards silently; either let a
  shard overrun for one oversized document (simplest, and what
  `write_shards`'s "append then check" loop already does) or cap document length
  with an explicit `--max-chars`. Say which in a comment, because the pretrain
  loop shuffles at file granularity and an unexpectedly huge file is a
  shuffle-quality problem, not just a size one.
- **Gutenberg headers.** PG19's text is largely stripped already, but check a
  handful of files for licence boilerplate at head and tail. Boilerplate
  repeated 28,602 times is a phrase the model will learn cold. If it is present,
  strip it; if it is not, say so in the docstring so the next reader doesn't
  re-check.
- **Use the `train` split only.** `test/` and `validation/` are held out by
  construction — the same reasoning `paths.py` gives for keeping `eval/` out of
  `input/`. `--heldout-mb` should draw from `validation/`, not from the tail of
  `train/`.

## Definition of done

- `data/input/Books` holds sharded text within the requested `--mb`.
- No network access; a missing source directory gives an actionable error.
- Only the `train` split is written to `input/`.
- The header/boilerplate question is answered in the docstring either way.

### Builder · 2026-08-10
Added `scripts/prepare_pg19.py`, reading the local `pg19/` tree with no network. Held-out text comes from the `validation/` split, never the tail of `train/`.

Boilerplate was measured before deciding: the standard `*** START/END ***` markers are already stripped (0%), but 78.5% carry an "End of the Project Gutenberg EBook" trailer and 74.3% a "Produced by" credit. Both are cut, edge-anchored so a novel mentioning Gutenberg mid-text keeps its words — measured 100% removal over 800 books. The `SMALL PRINT` licence block (3.9%) is left: no consistent opening, and not worth the false positives. All of this is recorded in the docstring.

Oversized documents: books average 400 KB and can exceed several MB, so each effectively becomes its own shard. Kept whole deliberately (better shuffle granularity than a book cut across three) and stated in the docstring; verified a 200 KB document is never split.
