# work/

Single source of truth for outstanding work: `ISSUE-NNNN.md` (bug/rule
violation), `TODO-NNNN.md` (task/feature), `EPIC-NNNN.md` (tracker for an
ordered child chain), sharing one number sequence.

The full spec — frontmatter, status lifecycle, priority/scope legends, the
append-only comment thread, and the epic convention — lives in
[`.claude/skills/shared/references/artifact-spec.md`](../.claude/skills/shared/references/artifact-spec.md).
Read it before adding or changing anything. Role constraints:
[`.claude/skills/shared/references/constraints.md`](../.claude/skills/shared/references/constraints.md).
