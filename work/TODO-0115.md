## Description

The assistant this model is being fine-tuned toward writes code — the SFT set's
`<|codeblock|>` and `<|code|>` markers exist for it, and
`prepare_smoltalk.py`'s converter deliberately refuses underscore emphasis
because that corpus is 11% code. But the pretrain corpus contains essentially no
real source code, so those markers wrap text the base model has never modelled.

**Wanted.** `scripts/prepare_code.py` on the TODO-0111 helper, writing sharded
text to `data/input/Code` under a `--mb` budget. Target ~10 GB, dialable down.

**Decisions to make and record in the docstring:**

- **Which repo.** `bigcode/the-stack-smol` (small, permissively-licensed, easy)
  or a `starcoderdata` slice (much larger) are the obvious candidates. Verify
  existence and schema before writing against it. Note that some code repos on
  the Hub are gated and need an accepted licence agreement — if the chosen one
  is, say so in the docstring and fail with an actionable message rather than a
  raw 401.
- **Which languages.** A `--langs` flag, defaulting to a handful that match what
  the assistant is actually asked about (Python, TypeScript, Rust, shell, plus
  markdown/documentation) beats taking 300 languages uniformly at this scale.
- **One file per document.** A source file is already a natural document
  boundary; do not concatenate unrelated files into one.

**Two things that will bite:**

- **Tokenizer budget.** The BPE trains on whatever this corpus contains at
  `max_vocab: 8192` (see ISSUE-0059). Code is dense in punctuation and
  identifiers and will compete hard for merges against prose. Adding 10 GB of it
  next to 40 GB of text is a real shift in what the tokenizer spends itself on.
  Flag this in the docstring; measuring it is a separate question, not this
  child's job.
- **Minified and generated files.** Lockfiles, bundles and vendored blobs are
  bytes without structure. Filter on line length and non-alphanumeric ratio, not
  just on total size.

## Definition of done

- `data/input/Code` holds sharded source files within the requested `--mb`.
- Language selection is a flag with a stated default.
- Minified/generated files are filtered out by a rule stated in the docstring.
- The chosen repo, its verified schema and any gating are documented.
