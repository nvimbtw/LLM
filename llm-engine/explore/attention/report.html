E2 — Attention anatomy

llm-engine/explore/attention · e2_attention.py · trained model diagfix (128d/4h/2L) vs a fresh init of the same shape, on a real 256-token window

What was done

Ran the frozen diagfix model and a randomly-initialised twin through one packed corpus window, and dumped the explicit attention weights. For every (layer, head) we measured what the LLM engine's diagnostics would not: entropy (normalised [0,1]), probability placed on position 0 (a mixed "read global state" mass), recency mass (probability on the last 2 keys), peak mass (mass on the single strongest key) and the weighted mean

Runs in ~3–4 s CPU.

Two findings. (1) Training widens layer-1 attention — entropy up to 0.94–0.96, peak mass down to ~0.06 (from ~0.09 at init): heads learn a diffuse "everything is relevant" distribution, they do not learn a sharp one-token copy head at this scale. (2) There is effectively no recency head in either state — softmax-normalised attention gives the last-visible token negligible mass, a real risk for any windowing/next-token task where the immediately recent context should matter.

Interesting / worrying

  • Layer 0 is already diffuse at init: a "no piece of the window is safe" default. Training keeps the same shape (entropy ~0.90) and only reduces the peak mass slightly — so most layer-0 heads never really specialize.
  • The trained layer-1 head that stands out is one with distance ~47 (mean attention distance) versus its peers ~56–70 — a slight "localish" preference, still far from a clean local/global split.
  • No "util color" per head at this scale; the LLM engine's softmax attention isn't built to learn a head-specialisation prior.

Why it would be a good addition

  • Learned per-head softmax temperature. One scalar/head applied in the score before softmax; init slightly >1. This is the cheapest lever to make attention either sharper (for location copy) or flatter (for summarising), and the LLM engine's attention path is self-contained so a logit_scale[head] vector fits in ~6 lines.
  • A rescaled / "recall head" budget. Give some heads a distinct scale (see the residual-idea note at the bottom of the training report) — otherwise a small model like this will never grow a true long-range copy head.

Verdict: cheapest, immediately-provable experiment in this reportcard. After one training run the diagnostics page would show the layer‑1 heads divide into a sharp cluster and a diffuse cluster — a cheap "does the model want a copy head?" test to keep in CI.

How it changes the workflow

  • Diagnostics get one more column: per-head entropy + peak under a supervised temperature, so the team can spot the "all-diffuse" failure at which point system temperatures are the answer.
  • Init-only head temperature from a warm/u-cool value could shorten the early local-context exploration that today takes the whole (short) training.
